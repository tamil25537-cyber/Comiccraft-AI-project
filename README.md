# ComicCraft - AI Comic Story Creator using Gemini Models

ComicCraft is a web-based AI-powered application that generates personalized comic book stories and illustrations from user-provided prompts. Built with **FastAPI**, **Google Gemini AI models** (`gemini-1.5-flash` and `gemini-1.5-pro`), and **Stable Diffusion / Diffusers**, ComicCraft streamlines comic storyline creation, dialogue writing, illustration rendering, and multi-page PDF generation.

---

## 🚀 Features

- **Personalized Comic Generation**: Customize story prompt, main character name, setting, tone, and art style.
- **5-Panel Structured AI Outline**: Fast outline and scene breakdown generated by Gemini Flash.
- **Rich Story Narration & Dialogues**: Immersive dialogue and scene narrations generated by Gemini Pro.
- **Comic-Style Illustrations**: Vivid panel artwork generated based on scene prompts.
- **Interactive Web Preview**: Clean panel-by-panel preview page.
- **Export to PDF**: Automatic compilation into a downloadable, multi-page comic PDF.
- **REST API Endpoints**: Full API support (`/generate-comic/json`, `/test-image`, `/generate`).

## 🛠️ Installation & Setup

1. **Clone or Navigate to the Project Directory:**
   ```bash
   cd "comic craft"
   ```

2. **Create & Activate Virtual Environment:**
   ```bash
   python -m venv comiccraft-env

   # Windows
   comiccraft-env\Scripts\activate

   # Linux/macOS
   source comiccraft-env/bin/activate
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure Environment Variables:**
   Update `.env` with your API keys:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   HF_API_KEY=your_huggingface_api_key_here
   ```

---

## 💻 Running the Application

Start the FastAPI development server:
```bash
uvicorn app.main:app --reload
```

- **Web Application:** Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in your browser.
- **Interactive Swagger API Docs:** Open [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

## 📡 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Comic creation input form |
| `POST` | `/generate` | Form-based comic generation returning preview HTML |
| `POST` | `/generate-comic/json` | JSON API endpoint returning layout & PDF path |
| `GET` | `/export-success` | Download confirmation page |
| `GET` | `/test-image` | Developer utility to test image generation |
